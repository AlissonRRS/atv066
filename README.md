# Site com 6 temas — HTML e CSS

Projeto de estudo com seis temas em um único arquivo (`index.html`):
- Sonic
- Mario
- Jair Bolsonaro
- Luiz Inácio Lula da Silva
- Max Steel
- Vasco da Gama

## Como abrir
Abra o arquivo `index.html` no navegador. Use o menu no topo para trocar de tema.

## Estrutura
- `index.html` — HTML, CSS e um pequeno JavaScript (para o menu) no mesmo arquivo
- `README.md` — descrição do projeto

O projeto utiliza seletores por ID e classe, cores, padding, margin, bordas, hover, display e meta viewport.
